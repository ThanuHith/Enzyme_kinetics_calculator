### *Turning biochemistry into code, and data into insight*

---

## 🧬 About the Project

This project is a computational implementation of **Michaelis–Menten kinetics**, designed to analyze enzyme behavior using real (or simulated) experimental data.

It takes substrate concentration and reaction velocity as input, then calculates the most important kinetic parameters:

* **Vmax** → Maximum reaction speed
* **Km** → Substrate affinity

…and visualizes everything in clean, publication-style graphs.

## 🧠 Core Equation

$$
v = \frac{V_{max}[S]}{K_m + [S]}
$$

Where:

* **v** = Reaction velocity
* **[S]** = Substrate concentration
* **Vmax** = Maximum velocity
* **Km** = Michaelis constant

## ⚙️ Features

✔️ Fit experimental data using non-linear regression
